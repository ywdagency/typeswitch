# TypeSwitch 0.1.0 — experimental preview

Build 2 refreshes installation instructions and adds automated checks of the packaged image, licenses, resources, source revision, and app metadata. The app's correction behavior is unchanged from build 1.

TypeSwitch corrects dictionary-backed words typed with the wrong English, Russian, or Ukrainian keyboard layout. Processing, settings, learned words, and exceptions stay on the Mac. Requires macOS 15 or newer.

This preview fixes continued typing during a correction: a bounded queue preserves following keyboard events in order, replacing the former 250 ms input suppression window. It also preserves replacement case, recognizes `what's` (`црфеэы` on the Russian layout), and recognizes curated uppercase abbreviations such as USB, SD, and SDI on the wrong layout. Russian recognition includes dictionary-backed inflected forms.

Immediate Esc restores the most recent eligible correction and saves a permanent exception for its original spelling and layout. Permission setup provides separate Input Monitoring and Accessibility actions.

Open the universal DMG, drag TypeSwitch into Applications, then open the installed app and grant both permissions through Settings → General. See [installation notes](https://github.com/ywdagency/typeswitch/blob/main/docs/installation.md). A checksum file accompanies the DMG. No developer tools are needed to run the app.

The current source passes 175 Swift tests and 15 Python tooling tests (3 dictionary-generator and 12 packaging checks). Automated event/control simulations cover rapid input, queue overflow, cancellation, focus changes, and undo releases. The user reported that a mixed-language fast-typing sample in Codex missed only `what's`; that dictionary fix awaits real-app retesting. Broader editor compatibility, queue cancellation in real apps, and Intel execution remain unverified. See the [observed compatibility matrix](https://github.com/ywdagency/typeswitch/blob/main/docs/compatibility.md).

This is experimental software. Test with disposable text. Secure fields, terminal contexts, ignored apps, stale input, and ambiguous tokens are refused. A timeout or interruption after part of a replacement has reached an app may leave a partial correction. Bundled dictionaries retain their separate licenses; source and full notices accompany this repository.
