# Security and privacy reports

TypeSwitch is experimental software that can observe keyboard events and replace text after macOS permission grants. A successful unit test run does not establish that every editor is safe.

For a possible security issue, use this repository's **Security → Report a vulnerability** feature when available. Do not post credentials, typed private text, diagnostics from a real session, or personal learned words in a public issue. If private reporting is unavailable, open a minimal issue requesting a private reporting channel without disclosing the sensitive details.

Reports about compatibility should use synthetic text in a controlled field. Include the macOS version, app name/version, input layouts, expected result, and observed result. Pause TypeSwitch or add the affected app to Ignored Apps if an unexpected rewrite occurs.
